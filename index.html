Fórmulas en acción

En este nivel los resultados están ocultos. Usa las fórmulas para calcular el alcance y luego compruébalo lanzando.

  1. Descomposición de la velocidad inicial
    vx = v0·cos θ
    vy0 = v0·sen θ
  2. Ecuaciones de posición (MRU en x · MRUV en y)
    x(t) = vx·t
    y(t) = h0 + vy0·t − ½·g·t²
  3. Altura máxima (cuando vy = 0)
    ts = vy0 / g
    H = h0 + vy0² / (2g)
  4. Tiempo de vuelo (cuando y = 0)
    tv = [vy0 + √(vy0² + 2·g·h0)] / g
  5. Alcance horizontal
    R = vx·tv
    Caso especial h0 = 0 → R = v0²·sen(2θ) / g
